## 3. Structural Enhancements in v2.2 vs v2.1.1

1. **Elimination of `shock_std` Trap**:
   - The ambiguous full-sample standardized column `shock_std` has been completely purged from all tables.
   - Replaced by raw monetary surprises (`shock_raw_bp`) for fold-safe scaling in estimation pipelines and descriptive benchmark scale (`shock_descriptive_2019`).
2. **Window Timing & Contamination Hygiene**:
   - Added `clr_1_clean`, defined strictly for decisions announced outside trading sessions (`announce_in_session == 0`).
   - Added `announce_in_session` and `in_session` indicator columns across all analysis tables.
3. **Pristine Test Split Architecture (`splits.csv`)**:
   - Added `read_by_prior_analysis` and `read_by_v1` flags.
   - Single Source of Truth `splits.csv` explicitly partitions the held-out test split (2024–2025, 70 decisions) into:
     - **Sample A (Full Test Split)**: 70 decisions (56 pristine + 14 prior-evaluated ECB decisions).
     - **Sample B (Pristine Test Split)**: Exactly 56 decisions with zero prior model exposure, zero interest rate hikes, and exclusively holds and cuts.
4. **Proprietary Level Stripping**:
   - Bit-for-bit verified that zero proprietary index levels (`level_local`) exist in any public release table.
