## 1. Executive Summary & Problem Formulation

In the exploratory analysis of MoTrans-15 v2.1.1, headline specifications exhibited conflicting inferential profiles across standard estimation routines:
- **Tier 1 Headline (`clr_5 ~ shock_raw_bp_fold_std`)**:
  - Homoskedastic OLS: $p = 1.4 \times 10^{-17}$
  - Clustered by `index_id`: $p = 6.3 \times 10^{-13}$
  - Clustered by `event_id`: $p = 0.3187$
  - Two-Way Clustered (`event_id` $\times$ `index_id`): $p = 0.3126$
  - Wild Cluster Bootstrap (Rademacher at `event_id`): $p = 0.3664$
  - Event-Level Block Permutation: $p = 0.0536$
- **Pooled Headline (`clr_5 ~ shock_raw_bp_fold_std + shock_tier`)**:
  - Homoskedastic OLS: $p = 1.99 \times 10^{-8}$
  - Clustered by `index_id`: $p = 4.61 \times 10^{-9}$
  - Clustered by `event_id`: $p = 0.0032$
  - Two-Way Clustered (`event_id` $\times$ `index_id`): $p = 0.0032$
  - Wild Cluster Bootstrap (Rademacher at `event_id`): $p = 0.5686$
  - Event-Level Block Permutation: $p = 0.0496$ (uncorrected $0.0494$)

This audit resolves these discrepancies by examining:
1. The exact permutation distributions under finite-sample $+1$ correction.
2. The exact unit of randomization in the block permutation routine.
3. The econometric source of divergence between asymptotic clustered OLS ($p = 0.0032$) and wild cluster bootstrap ($p = 0.5686$).
4. The confirmatory inference standard for this dataset.

## 3. Permutation Randomization Protocol (Task 1b)

A critical integrity requirement is verifying what the permutation algorithm actually shuffles:
1. **Unit of Randomization**: The permutation operates strictly at the **EVENT LEVEL** (`event_id`). It does **not** shuffle individual rows of the panel.
2. **Implementation Verification**:
   - In `scripts/update_placebo_and_multiplicity.py` (lines 79–86) and `scripts/audit_inference.py` (lines 43–50):
     ```python
     event_cols = ["event_id", "regime", "decision_date", shock_col]
     if "shock_tier" in df.columns:
         event_cols.append("shock_tier")
     events = df[event_cols].drop_duplicates().sort_values("decision_date")
     event_to_idx = {eid: idx for idx, eid in enumerate(events["event_id"])}
     row_event_idx = df["event_id"].map(event_to_idx).values
     ```
   - Each decision event $g$ has an assigned integer index in `events`. All 37 to 38 equity index rows corresponding to event $g$ map to the exact same position via `row_event_idx`.
   - Strata are formed by central bank $\times$ tier blocks: `strata_keys = list(zip(events["regime"], events["shock_tier"]))`.
   - For each draw $b$, shocks are permuted and circular-shifted strictly across events within each stratum.
   - The permuted event shock vector is projected back to the panel using `x_b = perm_s[row_event_idx]`.
   - **Conclusion**: All equity index returns for a given monetary policy decision receive the identical counterfactual shock. The correlation structure across assets within an event is perfectly preserved under the null.

## 5. Resolving the Econometric Discrepancy: Why Cluster OLS $p=0.003$ vs Wild Bootstrap $p=0.57$

The core econometric puzzle is why the pooled specification yields asymptotic cluster OLS $p = 0.0032$ ($t = 2.95$), yet wild cluster bootstrap produces $p = 0.5686$.

### 5.1 The Failure of Index-Level and Homoskedastic Clustering
First, note that clustering only by `index_id` or using homoskedastic OLS yields spuriously massive $t$-statistics ($t \approx 7.2$ to $8.5$, $p < 10^{-12}$). This is the textbook Moulton (1986) problem: because the shock variable is identical across all 38 indices on event day $g$, failing to cluster at the event level artificially inflates the effective sample size by a factor of $38$, shrinking standard errors by $\sqrt{38} \approx 6.16$. Clustering at the event level is mathematically indispensable.

### 5.2 Asymptotic Sandwich vs Restricted Wild Bootstrap in Pooled Panels
Why does asymptotic event-clustering produce $SE = 0.00065$ in Pooled, whereas Tier 1 had $SE = 0.00325$?
1. **Sample Heterogeneity and Leverage Points**:
   - Tier 1 contains 239 events with high-frequency monetary surprises (median absolute shock ~ 3–5 bps).
   - The pooled sample appends 110 Tier 2 events (inter-meeting daily yield changes from 10-year and 2-year government bonds), which have substantially larger standard deviations and fat-tailed shocks.
   - When standardized together, a handful of Tier 2 events with high volatility act as leverage points in the cross-product $X_g' u_g$.
2. **Asymptotic Sandwich Downward Bias**:
   - The cluster-robust sandwich estimator $\hat{V}_{\text{cluster}} = (X'X)^{-1} \left( \sum_{g=1}^G X_g' \hat{u}_g \hat{u}_g' X_g \right) (X'X)^{-1}$ relies on asymptotic normality ($G \to \infty$) and the assumption that the cluster scores $s_g = X_g' \hat{u}_g$ have well-behaved, bounded fourth moments.
   - When cluster sizes are unbalanced and cross-sectional error correlation is heterogeneous across event types, asymptotic cluster standard errors are notoriously prone to severe downward bias (Cameron & Miller, 2015; MacKinnon & Webb, 2017).
3. **The Finite-Sample Behavior of Wild Cluster Bootstrap**:
   - The restricted wild cluster bootstrap (Cameron, Gelbach, and Miller, 2008) directly addresses this failure:
     - It estimates the restricted model under $H_0: \beta_{\text{shock}} = 0$, obtaining restricted residuals $\tilde{u}_g$.
     - For each bootstrap draw $b$, it multiplies each entire cluster's residual vector by an independent Rademacher weight $w_g \in \{-1, +1\}$.
     - This preserves the entire within-cluster covariance structure across all 38 indices, the exact variance of each cluster, and the exact leverage structure of the $X$ matrix.
     - When re-estimating the $t$-statistic on the bootstrap data, the distribution of $t^*_b$ is heavy-tailed: realizations with $|t^*_b| \ge 2.95$ occur **56.86% of the time**.
   - Consequently, the asymptotic $t$-statistic of $2.95$ is well within the typical sampling variability of this panel under the null hypothesis of no monetary policy effect.

## 6. Primary Inference Standard and Multiplicity Adjustments (Task 1d)

### Standard Adopted
1. **Primary Standard**: **Restricted Wild Cluster Bootstrap (Rademacher at `event_id`)** is the primary inferential benchmark for confirmatory testing in MoTrans-15. Event-level block permutation provides non-parametric confirmation.
2. **Reporting Requirement**: Asymptotic clustered standard errors (clustered by `event_id`) and two-way clustered standard errors (`event_id` $\times$ `index_id`) must always be reported alongside wild cluster bootstrap $p$-values. Whenever asymptotic cluster $p$ and wild bootstrap $p$ diverge, the wild bootstrap $p$-value governs the empirical conclusion.
3. **Multiplicity Conclusion**: Under the primary inference standard, **zero out of 61 specifications** in `outputs/modeling/ledger.csv` achieve statistical significance after Holm-Bonferroni or Benjamini-Hochberg FDR correction. The dataset firmly represents an empirical null result under leakage-safe holdout validation.
