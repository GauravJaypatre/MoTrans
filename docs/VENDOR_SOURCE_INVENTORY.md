# MoTrans-15 Data Source & Vendor Inventory

All statements of terms, licences, and access URLs below are taken strictly from evidence recorded inside the repository (`data/raw/MANIFEST.csv`, `src/` collector modules, and `docs/` freeze documentation). No external terms of use are inferred or asserted.
